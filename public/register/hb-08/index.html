HB-08Resolved

Missing region stored as an empty string

Harborview Bank

What was wrong

Region is blank — an empty string, not a null.

299 rows; 298 after removing duplicates.

Evidence

How it was detected

2% empty; 6 distinct values (5 regions and blank)

Why it matters

A null check alone wouldn’t find it.

What was done

Filled from the home branch’s region (20,000 of 20,000 matched).

How it was verified

The quality log records the table’s state after its cleaning steps:

20,000 rows. gender has 2 values, income_band 4, region 5 with none blank, email 20,000 unique, birth_date 104 null, signup_date 0 errors. Every home_branch_id matches a branch.

02_Data_Quality_Log.md, line 41 ↗

Every KPI built on it was then reconciled against totals calculated outside Power BI.

Lesson recorded in the project“Missing values can be empty strings, not null. Check both.”
