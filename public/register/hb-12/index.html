HB-12Resolved

Two date formats in one column

Harborview Bank

What was wrong

YYYY-MM-DD and DD/MM/YYYY mixed together. 17/12/2022 proves the second format is day first.

Evidence

How it was detected

Value list; filter on "/"

Why it matters

A US-locale type change would have failed on 874 rows and silently swapped day and month on 549.

What was done

Custom column parsing each format separately, 0 errors.

How it was verified

The quality log records the table’s state after its cleaning steps:

20,000 rows. gender has 2 values, income_band 4, region 5 with none blank, email 20,000 unique, birth_date 104 null, signup_date 0 errors. Every home_branch_id matches a branch.
