HC-02Resolved

Patients with no city — kept, but set aside

Healthcare lakehouse

What was wrong

51 patients have no city.

Evidence

How it was detected

Null-count profile of every column.

Why it matters

Dropping them would lose real patients; keeping them in the main table would put blanks into every geographic breakdown.

What was done

Valid rows go to health.silver.patients; the 51 go to their own table instead of being deleted.

Show the PySpark
valid_patients = patients_clean.filter(
    F.col("city").isNotNull()
)
patients_missing_city = patients_clean.filter(
    F.col("city").isNull()
)
