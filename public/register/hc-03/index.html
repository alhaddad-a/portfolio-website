HC-03Resolved

Admissions with no admission date

Healthcare lakehouse

What was wrong

The very first admission in the 2021 file has every ID but no date. 105 admissions are like that.

105 of 500,000 admissions across the five yearly files.

Evidence

How it was detected

Null-count profile after consolidating the five yearly files.

Why it matters

An admission without a date can’t be counted in admissions_by_year, but its billing still exists.

What was done

The five yearly files are unioned first; rows without a date are written to a separate table.

Show the PySpark
valid_admissions = admissions.filter(
    F.col("admission_date").isNotNull()
)
admissions_missing_date = admissions.filter(
    F.col("admission_date").isNull()
)
