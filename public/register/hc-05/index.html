HC-05Checked · clean

Do the payments add up? Checked: yes

Healthcare lakehouse

What was wrong

Nothing — every bill’s two payments add up to its total, once rounded to the cent.

Evidence

How it was detected

Recomputed from the raw file, which is public in the project repository.

Why it matters

This is the check that makes the revenue Gold tables safe to sum.

How it was verified

A query that should return no rows after the fix.

Show the check
billing_mismatch = billing.filter(

        2
    ) != F.round(F.col("total_cost"), 2)
)
print(
