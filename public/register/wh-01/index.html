WH-01Resolved

Spaces before and after customer names

SQL Server warehouse · Databricks pipeline

What was wrong

The CRM export stores names with stray spaces: row 1 is “ Jon”, “Yang ”. Nothing about the value looks wrong in a table view.

17 first names and 22 last names carry a leading or trailing space; 29 rows in total.

Evidence

How it was detected

Recomputed from the raw file, which is public in the project repository.

Why it matters

“ Jon” and “Jon” are different strings. They split a GROUP BY, fail an equality join and sort apart from each other.

What was done

SQL Server Medallion Data Warehouse

TRIM() on both name columns in the Silver load.

Show the T-SQL
TRIM(cst_firstname) AS cst_firstname,
TRIM(cst_lastname) AS cst_lastname,

Databricks Medallion Pipeline

Trims every string column of the table in one loop, not just the ones known to be dirty.

Show the PySpark
for field in df.schema.fields:
    if isinstance(field.dataType, StringType):
        df = df.withColumn(field.name, trim(col(field.name)))

How it was verified

The repository’s whitespace check runs on cst_key; the name columns are trimmed on every load.

Show the check
-- Check for Unwanted Spaces
-- Expectation: No Results
SELECT 
    cst_key 
FROM silver.crm_cust_info
WHERE cst_key != TRIM(cst_key);
