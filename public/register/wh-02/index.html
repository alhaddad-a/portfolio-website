WH-02Resolved

One customer, two records

SQL Server warehouse

What was wrong

Some customers were exported twice. For ID 29433 the first copy has no name at all; the second, two days newer, is complete.

5 customer IDs appear more than once: 6 extra rows.

Evidence

How it was detected

Recomputed from the raw file, which is public in the project repository.

Why it matters

A duplicate key in a dimension doubles every fact row that joins to it.

What was done

Number each customer’s records by create date, newest first, and keep only the first.

Show the T-SQL
ROW_NUMBER() OVER (PARTITION BY cst_id ORDER BY cst_create_date DESC) AS flag_last
...
WHERE flag_last = 1; -- Select the most recent record per customer

How it was verified

A query that should return no rows after the fix.

Show the check
-- Check for NULLs or Duplicates in Primary Key
-- Expectation: No Results
SELECT 
    cst_id,
    COUNT(*) 
FROM silver.crm_cust_info
GROUP BY cst_id
HAVING COUNT(*) > 1 OR cst_id IS NULL;
