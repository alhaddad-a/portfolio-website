WH-04Resolved

Marital status stored as one-letter codes

SQL Server warehouse · Databricks pipeline

What was wrong

The CRM stores marital status as M and S, and leaves seven rows empty.

Evidence

How it was detected

Recomputed from the raw file, which is public in the project repository.

Why it matters

Codes are fine inside one system. In a warehouse that joins two systems, everybody reading the table has to know what they mean.

What was done

SQL Server Medallion Data Warehouse

Mapped to readable values; anything else becomes n/a.

Show the T-SQL
WHEN UPPER(TRIM(cst_marital_status)) = 'S' THEN 'Single'
WHEN UPPER(TRIM(cst_marital_status)) = 'M' THEN 'Married'
ELSE 'n/a'

Databricks Medallion Pipeline

Same mapping in PySpark.

Show the PySpark
F.when(F.upper(F.col("cst_marital_status")) == "S", "Single")
 .when(F.upper(F.col("cst_marital_status")) == "M", "Married")
 .otherwise("n/a")

How it was verified

A consistency review rather than a pass/fail check:

Show the check
-- Data Standardization & Consistency
SELECT DISTINCT 
    cst_marital_status 
FROM silver.crm_cust_info;
