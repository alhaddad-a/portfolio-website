WH-05Resolved

Gender missing in a quarter of CRM customers

SQL Server warehouse · Databricks pipeline

What was wrong

4,578 CRM customers have no gender. The ERP file CUST_AZ12 has its own gender column for the same customers.

Evidence

How it was detected

Recomputed from the raw file, which is public in the project repository.

Why it matters

Two systems disagree or have gaps; the model has to decide which one wins, and say so.

What was done

SQL Server Medallion Data Warehouse

Silver maps M/F to Male/Female. Gold treats the CRM as the primary source and falls back to the ERP when the CRM says n/a.

Show the T-SQL
WHEN ci.cst_gndr != 'n/a' THEN ci.cst_gndr -- CRM is the primary source for gender
ELSE COALESCE(ca.gen, 'n/a')  			   -- Fallback to ERP data

Databricks Medallion Pipeline

The same precedence rule in the Gold notebook.

Show the PySpark
CASE
    WHEN ci.gender <> 'n/a' THEN ci.gender
    ELSE COALESCE(ca.gender, 'n/a')
END AS gender,
