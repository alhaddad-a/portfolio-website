WH-06Resolved

Two keys packed into one product key

SQL Server warehouse · Databricks pipeline

What was wrong

The first five characters of every product key are a category code, written with a hyphen where the ERP category table uses an underscore.

Evidence

How it was detected

Recomputed from the raw file, which is public in the project repository.

Why it matters

Without splitting the key, products can’t be joined to their category, and sales can’t be joined to products.

What was done

SQL Server Medallion Data Warehouse

Split into two columns and align the separator with the ERP.

Show the T-SQL
REPLACE(SUBSTRING(prd_key, 1, 5), '-', '_') AS cat_id, -- Extract category ID
SUBSTRING(prd_key, 7, LEN(prd_key)) AS prd_key,        -- Extract product key

Databricks Medallion Pipeline

Same split in PySpark.

Show the PySpark
df = df.withColumn("cat_id", F.regexp_replace(F.substring(col("prd_key"), 1, 5), "-", "_"))
df = df.withColumn("prd_key", F.substring(col("prd_key"), 7, F.length(col("prd_key"))))
