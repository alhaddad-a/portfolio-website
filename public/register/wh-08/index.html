WH-08Resolved

Products with no cost

SQL Server warehouse · Databricks pipeline

What was wrong

Two products arrive with an empty cost.

Evidence

How it was detected

Recomputed from the raw file, which is public in the project repository.

Why it matters

A NULL cost makes any margin or cost total silently NULL too.

What was done

SQL Server Medallion Data Warehouse

Defaulted to zero.

Show the T-SQL
ISNULL(prd_cost, 0) AS prd_cost,

Databricks Medallion Pipeline

Same default in PySpark.

Show the PySpark
df = df.withColumn("prd_cost", F.coalesce(col("prd_cost"), F.lit(0)))

How it was verified

A query that should return no rows after the fix.

Show the check
-- Check for NULLs or Negative Values in Cost
-- Expectation: No Results
SELECT 
    prd_cost 
FROM silver.crm_prd_info
WHERE prd_cost < 0 OR prd_cost IS NULL;
