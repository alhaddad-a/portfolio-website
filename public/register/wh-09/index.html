WH-09Resolved

Products that end before they start

SQL Server warehouse

What was wrong

Half of the product history rows have an end date earlier than their start date.

Evidence

How it was detected

Recomputed from the raw file, which is public in the project repository.

Why it matters

Product history (which price applied when) can’t be trusted if a version ends before it begins.

What was done

Ignore the stored end date. Rebuild it as the day before the next version of the same product starts.

Show the T-SQL
CAST(
    LEAD(prd_start_dt) OVER (PARTITION BY prd_key ORDER BY prd_start_dt) - 1 
    AS DATE
) AS prd_end_dt -- Calculate end date as one day before the next start date

How it was verified

A query that should return no rows after the fix.

Show the check
-- Check for Invalid Date Orders (Start Date > End Date)
-- Expectation: No Results
SELECT 
    * 
FROM silver.crm_prd_info
WHERE prd_end_dt < prd_start_dt;
