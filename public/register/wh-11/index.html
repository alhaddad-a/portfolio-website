WH-11Resolved

Sales amounts that don’t equal quantity × price

SQL Server warehouse

What was wrong

The sales amount is sometimes missing, negative, or simply doesn’t match the quantity and price on the same line.

23 rows where the amount is missing, zero or negative, or doesn’t equal quantity × price.

Evidence

How it was detected

Recomputed from the raw file, which is public in the project repository.

Why it matters

Revenue is the number every report starts from. If the line total and its parts disagree, one of them is wrong.

What was done

When the amount is missing, not positive or inconsistent, recompute it from quantity × |price|.

Show the T-SQL
WHEN sls_sales IS NULL OR sls_sales <= 0 OR sls_sales != sls_quantity * ABS(sls_price) 
	THEN sls_quantity * ABS(sls_price)
ELSE sls_sales

How it was verified

A query that should return no rows after the fix.

Show the check
-- Check Data Consistency: Sales = Quantity * Price
-- Expectation: No Results
SELECT DISTINCT 
    sls_sales,
    sls_quantity,
    sls_price 
FROM silver.crm_sales_details
WHERE sls_sales != sls_quantity * sls_price
   OR sls_sales IS NULL 
   OR sls_quantity IS NULL 
   OR sls_price IS NULL
   OR sls_sales <= 0 
   OR sls_quantity <= 0 
   OR sls_price <= 0
ORDER BY sls_sales, sls_quantity, sls_price;
