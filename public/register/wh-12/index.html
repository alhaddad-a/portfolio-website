WH-12Resolved

Prices missing or negative

SQL Server warehouse · Databricks pipeline

What was wrong

Twelve sale lines have no usable unit price.

12 prices are empty, zero or negative (5 negative).

Evidence

How it was detected

Recomputed from the raw file, which is public in the project repository.

Why it matters

Price feeds every average-price and margin figure; a negative one flips the sign of whatever it touches.

What was done

SQL Server Medallion Data Warehouse

Derive the price from the line total.

Show the T-SQL
WHEN sls_price IS NULL OR sls_price <= 0 
	THEN sls_sales / NULLIF(sls_quantity, 0)
ELSE sls_price  -- Derive price if original value is invalid

Databricks Medallion Pipeline

Same derivation in PySpark, guarding against a zero quantity.

Show the PySpark
F.when(
    (col("sls_price").isNull()) | (col("sls_price") <= 0),
    F.when(
        col("sls_quantity") != 0,
        col("sls_sales") / col("sls_quantity")
    ).otherwise(None)
).otherwise(col("sls_price"))
