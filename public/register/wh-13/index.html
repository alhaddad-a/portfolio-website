WH-13Resolved

ERP customer keys with a three-letter prefix

SQL Server warehouse · Databricks pipeline

What was wrong

The ERP writes the same customer number as the CRM, but 11,042 of them start with NAS.

Evidence

How it was detected

Recomputed from the raw file, which is public in the project repository.

Why it matters

The ERP’s birth dates and genders can’t be joined to CRM customers until the keys match.

What was done

SQL Server Medallion Data Warehouse

Strip the prefix when present.

Show the T-SQL
WHEN cid LIKE 'NAS%' THEN SUBSTRING(cid, 4, LEN(cid)) -- Remove 'NAS' prefix if present
ELSE cid

Databricks Medallion Pipeline

Same rule in PySpark.

Show the PySpark
F.when(col("cid").startswith("NAS"),
       F.substring(col("cid"), 4, F.length(col("cid"))))
 .otherwise(col("cid"))
