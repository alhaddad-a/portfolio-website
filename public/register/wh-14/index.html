WH-14Resolved

Customers born in the future

SQL Server warehouse · Databricks pipeline

What was wrong

Sixteen ERP birth dates are in the future; four of them are in the year 9999.

16 birth dates lie in the future, from 2038 to 9999.

Evidence

How it was detected

Recomputed from the raw file, which is public in the project repository.

Why it matters

A single impossible birth date wrecks an age distribution and any “average age” figure.

What was done

SQL Server Medallion Data Warehouse

Birth dates after today become NULL.

Show the T-SQL
WHEN bdate > GETDATE() THEN NULL
ELSE bdate

Databricks Medallion Pipeline

Same rule in PySpark.

Show the PySpark
F.when(col("bdate") > F.current_date(), None)
 .otherwise(col("bdate"))

How it was verified

A query that should return no rows after the fix.

Show the check
-- Identify Out-of-Range Dates
-- Expectation: Birthdates between 1924-01-01 and Today
SELECT DISTINCT 
    bdate 
FROM silver.erp_cust_az12
WHERE bdate < '1924-01-01' 
   OR bdate > GETDATE();
