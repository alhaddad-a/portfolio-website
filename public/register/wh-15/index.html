WH-15Resolved

Nine spellings of two genders

SQL Server warehouse · Databricks pipeline

What was wrong

The ERP gender column mixes full words, single letters, letters with a trailing space, and values that are only spaces.

Evidence

How it was detected

Recomputed from the raw file, which is public in the project repository.

Why it matters

Counting by gender over this column gives nine groups instead of two (plus unknown).

What was done

SQL Server Medallion Data Warehouse

Trim, upper-case, accept both forms.

Show the T-SQL
WHEN UPPER(TRIM(gen)) IN ('F', 'FEMALE') THEN 'Female'
WHEN UPPER(TRIM(gen)) IN ('M', 'MALE') THEN 'Male'
ELSE 'n/a'

Databricks Medallion Pipeline

Same rule after the all-columns trim.

Show the PySpark
F.when(F.upper(col("gen")).isin("F", "FEMALE"), "Female")
 .when(F.upper(col("gen")).isin("M", "MALE"), "Male")
 .otherwise("n/a")

How it was verified

A consistency review:

Show the check

    gen 
FROM silver.erp_cust_az12;
