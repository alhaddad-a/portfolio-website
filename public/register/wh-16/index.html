WH-16Resolved

A hyphen in every location key

SQL Server warehouse · Databricks pipeline

What was wrong

The location file writes customer numbers with a hyphen the other two files don’t use.

Evidence

How it was detected

Recomputed from the raw file, which is public in the project repository.

Why it matters

Without the fix, not one customer gets a country.

What was done

SQL Server Medallion Data Warehouse

Remove the hyphen.

Show the T-SQL
REPLACE(cid, '-', '') AS cid,

Databricks Medallion Pipeline

Same rule in PySpark.

Show the PySpark
df = df.withColumn("cid", F.regexp_replace(col("cid"), "-", ""))
