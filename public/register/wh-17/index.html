WH-17Resolved

One country, three spellings

SQL Server warehouse · Databricks pipeline

What was wrong

Country names are mixed with ISO-style codes, and some values are empty or only spaces.

2,591 USA, 1,500 US, 566 DE, 332 empty and 5 made only of spaces.

Evidence

How it was detected

Recomputed from the raw file, which is public in the project repository.

Why it matters

Sales by country would show the United States three times.

What was done

SQL Server Medallion Data Warehouse

Map codes to names; empty or blank becomes n/a.

Show the T-SQL
WHEN TRIM(cntry) = 'DE' THEN 'Germany'
WHEN TRIM(cntry) IN ('US', 'USA') THEN 'United States'
WHEN TRIM(cntry) = '' OR cntry IS NULL THEN 'n/a'
ELSE TRIM(cntry)

Databricks Medallion Pipeline

Same mapping in PySpark.

Show the PySpark
F.when(col("cntry") == "DE", "Germany")
 .when(col("cntry").isin("US", "USA"), "United States")
 .when((col("cntry") == "") | col("cntry").isNull(), "n/a")
 .otherwise(col("cntry"))

How it was verified

A consistency review:

Show the check
-- Data Standardization & Consistency
SELECT DISTINCT 
    cntry 
FROM silver.erp_loc_a101
ORDER BY cntry;
